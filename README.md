# 你好

> **任何东西交出去之前，先证明"机器能读、机器能跑"。**

这是我做所有事情的一条标准。它不是口号 —— 下面每个项目都在证明它。

最后更新：2026-10-20

## 如果你只有 2 分钟

时间紧，按这个顺序看：

1. **`lbm-probe`**（最新）— 一个 CFD（计算流体力学，Computational Fluid Dynamics）数值实验：
   在普通 CPU 上复现圆柱绕流，与权威基准逐项对照，**Cd 与 St 最好档误差 0.06% / 0.02%**。
   连我自己一度恒定测错的 7.6%，都被查回来写进了 README。**它证明我会用实测数据说话。**
2. **`personal-ai`** — 主项目。跑在自己电脑上的 AI 入口：对话与待办全部存在本地，
   模型供应商可替换，32/32 测试全过。
3. **`pdf-delivery-audit`** — 最小但最直接。我所有交付标准的起点（就是上面那条标准的来历）。

其余四个按需看：一个是同类型的研究项目（`three-body-trust-horizon`），三个是工具 / 能力件。

## 这条标准是怎么来的

有一次我把简历导成 PDF，页面上排版整齐、字体清晰，看着完全正常。
我用程序去读它的时候发现：**里面一个可提取的字符都没有** —— 它是一张图，不是文字。
招聘系统（ATS，简历自动解析系统）读它，等于读一张白纸。

代价不是"有点遗憾"，是**不可逆的投递窗口**丢掉了。

从那以后我给自己定了这条标准，并把它做成了工具：
**发任何东西之前，先按"对方系统"的方式验一遍。**

## 我的方法是怎么一版版改出来的

我更愿意把这块当成正文。它比项目列表更能说明我怎么工作 ——
**下面每一版，都是被一次真实的失败推着改的，不是规划出来的。**

| 版本 | 触发事件（真实失败） | 固化成什么规矩 |
|---|---|---|
| **v1 · 自己写** | 交出去的东西"人眼看着对"但机器读不出 | 此时还没有规矩 |
| **v2 · AI 协同**（10-08 起） | ① 简历 PDF 人眼正常、机器 0 字符可读<br>② CI 在 Windows 全红，我第一反应是怪环境 | 「看着对 ≠ 能用」→ 交付前必须验证对方系统能读<br>「不再凭感觉归因」→ 先实测再下结论 |
| **v3 · 写的人不审自己**（10-11 起） | 我自己验自己的活，把"本机缓存凭据无权"误判成"所有令牌都无权" | **作者不做自己的验收者** → 交另一个 AI 独立复核 |
| **v4 · 自动回归**（10-14 已完成） | 改一次提示词还得手动跑评测，才知道变好还是变差 | 评测集挂进 CI：**push / PR / 每周一自动跑，成绩差于基线就直接亮红灯**；基线只能显式更新，不会被自动抬高而失效 |

**v3 那条值得多说一句。** 我当时的错误有两类：一是判断错，二是**用错了验证方法** ——
我查了 API 的权限字段，四枚令牌都显示可写就以为能推，但那个字段表示的是"账号对仓库的权限"，不是"令牌的权限"，owner 查自己的仓库永远是 true。

根因不是技术，是**我自己验我自己的活**。所以现在的规矩是：

> **作者不做自己的验收者。** 复核方不采信被审方的说法，全部自己重跑一遍；
> 结论分三档 —— 通过 / 部分实证 / 无法独立复核，**最后一档不许编**。

这套机制后来抓出过：我自己的误判、一句"真实但读者点不开证据"的表述被判轻度夸大、
四处隐私漏网（其中一处是此前扫描漏掉的）。**我的工作方式本身是能被修正的。**

**v4 已经落地了。** 现在改一次提示词，不用我记得去跑——CI 会自己跑，
成绩掉下去就亮红灯，还会告诉我具体是哪几条用例退回去了。
这一步的意义不只是省事：**它把"持续演进"从靠自律，变成了靠机制。**

## 关于协作方式（我不含糊这一条）

这些项目的**代码由我与 AI 编程助手协作完成**：
我负责定义问题、设定验收标准、判断结果对不对；代码由 AI 生成。

我不把它说成"我一个人手搓了所有代码"，因为那不诚实。
但我也不觉得它就不算数 —— 真正稀缺的从来不是敲代码这个动作，
而是**定义问题、设定标准、识别出"这看着对其实不对"**。这三件事我是实的。

## 几条我坚持的规矩

- **不把推测说成实测。** 凡未实测的，文档里一律明确标注。
  比如提示词评测跑的是离线模拟后端，**我会写清楚"这不是真实模型成绩"**。
- **只读的体检工具绝不擅自修改。** 机器巡检只报不改，
  而且有一条自动检查盯着：源码里出现"删除""停止服务"，测试立刻失败。
- **谁写的谁不许判合格。** 我的产出交给另一个视角独立验，反之亦然。
